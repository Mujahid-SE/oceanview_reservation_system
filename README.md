Ocean View Resort Reservation System

## Project Description
The Ocean View Resort Reservation System is a web-based application developed to manage hotel reservations efficiently. The system allows staff and administrators to add, view, and manage reservations while maintaining customer data in a structured database.

The system was developed as part of a Software Engineering assignment to demonstrate system design, architecture implementation, testing, and version control practices.

## Technologies Used
- Java
- JSP
- Apache Tomcat
- MySQL Database
- HTML / CSS
- JUnit Testing
- Git & GitHub

## System Features
- User login authentication
- Add new reservations
- View existing reservations
- Bill calculation
- Help page for system guidance
- Logout functionality
- Role-based access (Admin / Staff)

## System Architecture
The system follows a simple three-tier architecture:
1. Presentation Layer (JSP user interfaces)
2. Business Logic Layer (Java classes and servlets)
3. Data Layer (MySQL database)

## Testing
JUnit testing was implemented to verify key functionalities of the system. Automated test cases were executed to ensure the reliability of the application.

## Version Control
The project source code is maintained using Git and hosted on GitHub. Multiple commits were made during the development process to track system improvements and feature additions.
